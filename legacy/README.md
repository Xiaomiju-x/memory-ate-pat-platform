# Legacy source snapshots

This directory preserves earlier team-authored implementations for study and
historical comparison. They are not the supported entry point, are excluded from CI,
and may lack fixes present in the current root application.

- `tkinter/at24c02_pat_generator.py`: the earlier tkinter-only snapshot kept during
  the CustomTkinter migration.

Use [`../at24c02_pat_generator.py`](../at24c02_pat_generator.py) for current work.
Do not build or publish a legacy snapshot as the current competition deliverable.
