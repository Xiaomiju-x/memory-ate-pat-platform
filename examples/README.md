# Examples

The reproducible current AT24C02 example package is stored in [`../output/`](../output/)
and can be regenerated with `python generate_samples.py`.

`legacy/` preserves earlier team-authored output snapshots so readers can compare the
project's evolution:

- `root-v1/`: the earliest small root-level PAT examples;
- `batch-v1/`: an older complete batch package;
- `batch-v6/`: a later package that also demonstrates STIL and WGL export.

Legacy outputs are evidence and learning material, not the current validation
baseline. Regenerate `output/` or use the tested CLI when evaluating present code.
